# synapse-stack

Matrix homeserver (Synapse) + Element Web client UI. Own Tailscale node **`synapse`**.
Standalone successor to the synapse service that lived inside `turnstone-stack`
(split out 2026-10-24; deployed on tva).

## Role in the Fleet

Matrix chat for the fleet — text messaging + federation. The homeserver's
`server_name` is **`synapse.tail6a7569.ts.net`**, which MUST stay equal to the
Tailscale cert domain (both derive from `TS_HOSTNAME` + `TAILNET_DOMAIN`) so
clients can connect to `https://synapse.tail6a7569.ts.net` directly.

Not included vs turnstone's old synapse: LiveKit/MSC4143/coturn (no LiveKit SFU
on tva — Element Call voice/video is not wired up), and the in-memory SQLite
DB (replaced with persistent storage).

## Services

| Container | Image | Role |
|---|---|---|
| `synapse-tailscale` | `tailscale/tailscale:latest` | Userspace tailscaled + SERVE (:443 → client API, :8451 → Element Web, raw TCP :7007 → dozzle-agent, raw TCP :8448 → federation). Not managed by watchtower (no label). |
| `synapse-app` | `matrixdotorg/synapse:latest` | The homeserver. SQLite DB + media + uploads in `./synapse/data/`; config rendered from committed `homeserver.yaml.template`. **Not** managed by watchtower — forward-only schema migrations; update deliberately via `make upgrade`. |
| `synapse-element-web` | `vectorim/element-web:latest` | Web client UI; config rendered into `./element-web/config.json` (homeserver base URL = cert domain). Managed by watchtower. |
| `synapse-dozzle-agent` | `amir20/dozzle:latest` (`agent`) | Reports this stack's containers to the central Dozzle hub over mTLS gRPC on :7007. Managed by watchtower. |
| `synapse-watchtower` | `containrrr/watchtower:latest` | Auto-updates labeled services hourly with rolling restart and rollback on healthcheck failure. Polls every 3600s. |

## Data

| Data | Location | Type |
|------|----------|------|
| SQLite DB, media store, uploads, signing key, rendered homeserver.yaml | `./synapse/data/` bind mount (700) | Local disk — back up this dir to preserve accounts/media/signing identity |
| Element Web config.json | `./element-web/config.json` bind mount (ro) | Generated by local-setup from .env |
| Tailscale node state | `./ts_state/` bind mount | Node identity — never delete |

## Secrets

| File | Source | Used By |
|---|---|---|
| `.tailscale-authkey` | Copied from `$STACK_ENV_DIR` by setup | Tailscale sidecar auth |
| `.synapse_macaroon_secret` | Generated by `setup.sh local-setup` (`openssl rand -hex 64`) | Rendered into homeserver.yaml (Macaroon signing) |
| `.registration_shared_secret` | Generated by `setup.sh local-setup` (`openssl rand -hex 32`) | Rendered into homeserver.yaml; gates `/register` — accounts created via `register_new_matrix_user` |
| `.dozzle-cert.pem`, `.dozzle-key.pem` | Copied from `$STACK_ENV_DIR` | Dozzle agent mTLS credential |

The ed25519 signing key is auto-generated by Synapse on first start at
`synapse/data/signing.key`.

## SERVE Config

```json
{
  "Web": {
    "${TS_CERT_DOMAIN}:443":  { "Handlers": { "/": { "Proxy": "http://synapse-app:8008" } } },
    "${TS_CERT_DOMAIN}:8451": { "Handlers": { "/": { "Proxy": "http://synapse-element-web:80" } } }
  },
  "TCP": {
    "443":  { "HTTPS": true },
    "8451": { "HTTPS": true },
    "7007": { "TCPForward": "synapse-dozzle-agent:7007" },
    "8448": { "TCPForward": "synapse-app:8448" }
  }
}
```

- `https://synapse.<tailnet>.ts.net` → client API + `.well-known` (the homeserver URL for all clients)
- `https://synapse.<tailnet>.ts.net:8451` → Element Web UI
- :7007 → dozzle-agent (raw TCP, mTLS gRPC log collection)
- :8448 → federation API — raw-TCP forward because userspace tailscaled only delivers traffic it forwards; a host port-map would be unreachable from the tailnet. Federation is plain HTTP but long-lived, so raw TCP is the safe route.

## Ops Notes

```sh
# Create an account (registration is closed to the public):
podman exec synapse-app register_new_matrix_user \
    --server-baseurl http://localhost:8008 -c /data/homeserver.yaml \
    -u <user> -p '<pass>'            # add -a for admin

# Health probe (image ships curl):
podman exec synapse-app curl -f http://localhost:8008/health
```

- The image entrypoint drops to uid 991 when run as container root — compose sets
  `UID=0 GID=0` so it stays container-root, which under rootless podman maps to the
  host stack user. Do not remove those env vars or data-dir ownership breaks.

- `trusted_key_servers: []` — federation keys fetched directly from peers (no
  public key server trust). Add `matrix.org` in the template for public-network interop.
- Config changes: edit `homeserver.yaml.template`, then `make local-setup && make restart`.
  The rendered file is regenerated on every local-setup (idempotent) — never hand-edit it.
